# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

NMEA Simulator X opens network listeners (TCP, UDP, WebSocket) and parses files supplied by the
user (GPX, KML, logs), so security reports are taken seriously.

Please do **not** open a public issue for a vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/Dimitrios-Kafetzis/NMEA_Simulator_X/security/advisories/new)
or email <dimitrioskafetzis@gmail.com>. You will receive an acknowledgement within seven days
and a fix or mitigation plan within thirty days for confirmed issues.

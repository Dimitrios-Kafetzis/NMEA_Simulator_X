# How-to guides

Task-oriented instructions for people who already know what they want to achieve.

- [Install on Windows, macOS or Linux](install.md), including the one-time warnings shown
  for unsigned software.
- [Build from source](build-from-source.md) on any of the three platforms.
- [Run the simulator headless](run-headless.md) to feed a plotter, broadcast on a network or
  generate test fixtures from the command line.

Guides for connecting specific software (OpenCPN, Signal K server, Google Earth), configuring
each transport and using the command-line tool are added together with those features.

# Tutorials

Tutorials are step-by-step lessons that take a newcomer from nothing to a working setup.

- [Your first simulated voyage](first-voyage.md): start the desktop application, watch the
  sentences in the console, steer from the keyboard and connect a chart plotter over TCP.

Planned for later milestones:

- *Following a GPX track*: load a recorded track and replay it as live data.
- *Recording and replaying a log*: capture a session and play it back.

The [build from source guide](../how-to/build-from-source.md) explains how to get a build
until installers are published.

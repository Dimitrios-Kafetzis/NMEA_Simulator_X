# Tutorials

Tutorials are step-by-step lessons that take a newcomer from nothing to a working setup.
They arrive with the first usable desktop build in milestone M2:

- *Your first simulated voyage*: start the simulator, watch the sentences in the console and
  connect a chart plotter over TCP.
- *Following a GPX track*: load a recorded track and replay it as live data.
- *Recording and replaying a log*: capture a session and play it back.

Until then, the [build from source guide](../how-to/build-from-source.md) is the best way
to get involved.
